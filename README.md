# Utilix — Community-Powered Developer Playground

**Developer tools. Mini apps. One community.**

Utilix is an open-source developer playground that brings together useful developer utilities and productivity applications in one platform.

Instead of navigating multiple websites, developers can discover and use different tools directly within Utilix.

## ✨ Core Modules

### 1. Developer Toolbox

A collection of browser-based developer utilities.

- JSON formatter and validator
- Base64 and URL encoder/decoder
- UUID and password generators
- Hash generator and JWT decoder
- Text utilities and converters

### 2. MiniApps Hub

A collection of small productivity applications.

- Habit Tracker
- Focus Timer
- Bookmark Manager
- Markdown Editor
- And more community-built applications.

## 🚀 Key Features

- Use tools directly within the platform.
- Search and discover tools and mini-apps.
- Save favorite tools for quick access.
- Personalized workspace.
- Dark and light themes.
- Offline support for compatible tools.
- Community-driven development.

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Additional:** PWA, IndexedDB, GitHub Actions

## 🤝 Contributing

Utilix is built for the developer community, and contributions are welcome!

You can contribute by:

- Creating new developer utilities.
- Building new productivity mini-apps.
- Improving existing features.
- Fixing bugs.
- Enhancing UI/UX.
- Improving documentation and tests.

Whether you're a beginner or an experienced developer, you're welcome to contribute!

## 📌 Project Status

Utilix is currently in its initial development stage. The platform is being built incrementally, with community contributions helping expand its collection of tools and mini-apps.
