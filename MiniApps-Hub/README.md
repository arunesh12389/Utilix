# Mini Apps 

A collection of small, independent web applications built and contributed by the community.

## Available Apps

This section will showcase community-built mini applications.

Examples:
- Habit Tracker
- Pomodoro Timer
- Notes App
- Expense Tracker
- Password Generator

## Contributing

Want to build and contribute a mini app?

1. Create a separate folder for your application inside `mini-apps/`.
2. Include all required source files and dependencies.
3. Add a README explaining the app and how to run it.
4. Ensure your application works independently.
5. Submit a Pull Request following the main contribution guidelines.
